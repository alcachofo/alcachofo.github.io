A notes app that is one HTML file: no dependencies, no build step, no server. Open it in a browser and everything is encrypted and decrypted right there, with a master password that never leaves the machine. Notes sync to a private GitHub repo of your own, which only ever stores ciphertext.

## Features

- Nested folders, drag and drop, rich text and tables, with undo that covers structural changes too
- Notes made of real A4 pages that paginate as you type, with designs you can import and export
- A built-in PDF writer: what you see on the pages is what you export, with no metadata, and censored text and images never reach the file
- Attachments of any type up to 200 MB, with EXIF and GPS data stripped from images
- A real merge on sync (a conflict becomes a copy, nothing gets overwritten), a 30-day trash, and weekly and monthly encrypted backups

## Security

- AES-256-GCM, with the key derived by PBKDF2-SHA256 at 1,200,000 iterations and a fresh IV on every save
- Attachments under their own key, each bound to its id so files cannot be swapped in the repo
- A brute-force guard: 3 seconds per attempt, and a 30-day lockout after 10 failures
- The repo and the browser storage only ever hold ciphertext
- It only ever syncs to a private repo: until you point it at yours it sends nothing, and it refuses any repo that is public

The [README](https://github.com/Alc4chofo/encrypted-notes#readme) explains how to set it up with your own private repo, and [How it works](https://github.com/Alc4chofo/encrypted-notes/blob/main/HOW-IT-WORKS.md) documents the threat model, the cryptography, the file formats and the sync protocol in detail.
